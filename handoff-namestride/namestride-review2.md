- **[P2] Thread the injected strings list through table-byte accounting too** — `main/build/battletables.js:521`. `battleTables(project, battleStrings)` now emits both the `BS_*` equates and `bs_text` from the injected list, but `battleTableBytes(project)` still calls `battleTables(project)` with the module default. Consequently, a valid injected 21-entry list emits a table measured at 584 bytes by `emittedBytes(battleTables(project, list))`, while `battleTableBytes(project)` reports 464 bytes; `battleRegionBytes` inherits the same 120-byte undercount. The new test at `test/unit/bankedbytes.test.js:243` cannot catch this because its only injected case has 22 entries and throws before either emission site is reached—reverting both emission sites to `BATTLE_STRINGS` would leave that test green. Give `battleTableBytes` the same optional list and add a 21-entry integration control that compares its count with the injected emission (or otherwise keep the injectable path and its byte counter tied to the same source).
